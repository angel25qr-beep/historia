JAVASCRIPT

¿Qué es JavaScript?

JavaScript es un lenguaje de programación que permite agregar funciones interactivas y dinámicas a las páginas web.

¿Para qué sirve?

  • Crear interactividad.
  • Responder a acciones del usuario.
  • Modificar elementos de una página.
  • Validar información.
  • Crear diferentes funciones.

Características

Característica Descripción
Interactividad Permite responder a acciones del usuario.
Programación Permite utilizar variables, funciones y condiciones.
Web Se utiliza principalmente en páginas y aplicaciones web.
