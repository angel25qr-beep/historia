EXAMEN CONTESTADO

En esta sección se presentan algunos ejemplos de preguntas relacionadas con los temas vistos durante el curso.

Preguntas y respuestas

  1. ¿Qué es HTML?

    Es un lenguaje utilizado para crear y estructurar páginas web.

  2. ¿Para qué sirve CSS?

    Sirve para darle diseño y estilos a una página web.

  3. ¿Qué es un hipervínculo?

    Es un enlace que permite acceder a otra página, documento o sitio web.

  4. ¿Qué es un hosting?

    Es un servicio donde se almacenan los archivos de un sitio web.

  5. ¿Qué es una tabla?

    Es una estructura que permite organizar información mediante filas y columnas.
