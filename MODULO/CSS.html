CSS Y DISENO

¿Que es CSS?

CSS significa Cascading Style Sheets. Se utiliza para darle diseno y apariencia a las paginas web.

¿Para que sirve?

  • Cambiar colores.
  • Cambiar tamanos.
  • Cambiar tipos de letra.
  • Modificar fondos.
  • Dar diseno a tablas.
  • Dar estilo a enlaces y botones.

Selectores

Selector Ejemplo Uso
Etiqueta p Aplica estilos a los parrafos.
Clase .titulo Aplica estilos a elementos con una clase.
ID #principal Aplica estilos a un elemento especifico.

Unidades de medida

  • px - pixeles
  • % - porcentaje
  • em - tamano relativo
  • rem - tamano relativo a la raiz
  • vw - ancho de la ventana
  • vh - alto de la ventana

Teoria del color

Los colores permiten mejorar la apariencia de una pagina web y ayudan a transmitir diferentes sensaciones.

Color Ejemplo de uso
Rojo Advertencias o elementos importantes.
Azul Confianza y tranquilidad.
Verde Naturaleza o seguridad.
Amarillo Atencion y energia.
