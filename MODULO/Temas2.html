Hosting

El hosting es un servicio que permite almacenar los archivos de un sitio web para que puedan estar disponibles en Internet.

Tipos de hosting

  • Hosting compartido.
  • Servidor VPS.
  • Servidor dedicado.
  • Hosting en la nube.

Dominio

El dominio es el nombre que se utiliza para acceder a un sitio web en Internet.

Dirección IP

Una dirección IP identifica un dispositivo o servidor dentro de una red.

WWW

WWW significa World Wide Web y se relaciona con el sistema de páginas y recursos que pueden consultarse mediante Internet.

Bootstrap

Bootstrap es un framework que proporciona herramientas prediseñadas para facilitar el diseño de sitios web.
