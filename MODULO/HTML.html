HTML

¿Que es HTML?

HTML significa HyperText Markup Language. Es el lenguaje utilizado para crear y estructurar el contenido de las paginas web.

¿Para que sirve?

HTML sirve para organizar textos, imagenes, enlaces, tablas, listas, formularios y otros elementos dentro de una pagina web.

Estructura basica

  1. DOCTYPE
  2. HTML
  3. HEAD
  4. BODY

Etiquetas basicas

Etiqueta Funcion
h1 Crear un titulo principal.
p Crear un parrafo.
img Insertar una imagen.
a Crear un hipervinculo.
table Crear una tabla.
ul Crear una lista desordenada.

Estructura semantica

  • header
  • nav
  • main
  • section
  • article
  • footer

Pagina web y sitio web

Una pagina web es un documento que puede ser visto mediante un navegador. Un sitio web esta formado por varias paginas relacionadas entre si.
