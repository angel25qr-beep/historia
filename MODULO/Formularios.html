FORMULARIOS EN HTML

¿Qué es un formulario?

Un formulario sirve para ingresar información en una página web, como el nombre, la edad o el correo electrónico.

Características

  • Permiten escribir información.
  • Organizan los datos del usuario.
  • Se utilizan en páginas web.

GET y POST

Método Función
GET Envía datos mediante la dirección web.
POST Envía datos dentro de una solicitud.
